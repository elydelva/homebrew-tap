# Catalogue Homebrew pour Frame

Le dépôt `elydelva/homebrew-tap` fournit un catalogue Homebrew conventionnel sous `Formula/`. Sa première entrée est la CLI `frame`, installable avec `brew install elydelva/tap/frame`. Une installation doit placer `frame` dans le `PATH` et `frame --version` doit correspondre à la version publiée.

La formule référence une GitHub Release immuable de `elydelva/frame`, avec un SHA-256 pour chaque archive prise en charge. La distribution initiale couvre macOS arm64 et x86_64, ainsi que Linux arm64 et x86_64. Les archives contiennent un exécutable autonome ; l'utilisateur n'a pas à installer Bun ou Node.

Le tap décrit l'installation, la mise à jour et la procédure d'ajout d'une formule. Chaque modification de formule passe une validation Ruby, `brew audit` et un test d'installation sur les plateformes annoncées. La publication initiale du tap doit rendre le dépôt distant accessible aux utilisateurs ; son état actuel est privé.

La branche `release` de `frame` est le point de promotion des versions CLI. Chaque push sur cette branche lance la construction d'une release CLI immuable et crée ou actualise une PR de mise à jour de `Formula/frame.rb` dans `homebrew-tap`. Chaque push destiné à la publication doit porter une version CLI inédite ; une version déjà publiée échoue sans remplacer ses archives. La PR est fusionnée automatiquement une fois les contrôles obligatoires réussis ; sa fusion rend la nouvelle formule disponible dans le tap, puis `brew update` et `brew upgrade` permettent son installation chez les utilisateurs.
